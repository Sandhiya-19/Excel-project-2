# Customer Support Performance Dashboard in Excel

This project presents an interactive **Customer Support Performance Dashboard** created using **Microsoft Excel**.  
The dashboard analyzes customer service call data and provides insights into agent performance, call resolution efficiency, and customer satisfaction.

## Project Objective

The objective of this project is to build a **customer support performance dashboard** that helps analyze call center performance, agent productivity, and customer satisfaction using Excel-based data visualization.

---

## Key Metrics

The dashboard highlights the following key performance indicators:

- **Total Calls:** 70,994
- **Resolution Rate:** 85%
- **Average Handle Time (AHT):** 5.81 minutes
- **Customer Satisfaction Score (CSAT):** 3.5

These metrics help evaluate the efficiency and effectiveness of the support team.

---

## Dashboard Insights

The dashboard provides several analytical views:

### Call Volume Trend
Shows the monthly call volume to understand demand patterns across different months.

### Resolved Calls by Agent
Compares the number of total calls and resolved calls handled by each support agent.

### Top Performing Agents
Highlights the **Top 3 agents based on resolved calls**.

### Team Performance
Displays the total calls handled by each support team:
- Complaint Registration
- EV Support
- Roadside Assistance
- Sales Enquiry
- Service Feedback
- Spare Parts

### Interactive Filters
The dashboard includes slicers to filter data by:

- **Call Type** (Inbound / Outbound)
- **Agent Name**
- **Support Team**

These filters allow dynamic analysis of the data.
